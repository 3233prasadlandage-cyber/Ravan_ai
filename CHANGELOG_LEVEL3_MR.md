# Change log — RAVAN AI

## v1.4.0 — Free-first Creator + Channel Toolkit
- Added a multi-asset local MP4 composition path using Media3 Transformer.
- Supports up to 20 selected photo/video inputs, timed stills, optional looped music, static title overlay, 16:9/9:16 layout, simple colour presets and export to Movies/RAVAN AI.
- Added YouTube title/description/tag draft fields and clipboard copy.
- Added safe explicit HTTP(S) website opening in the default browser.
- Updated backend assistant instructions to describe built-in editor correctly and avoid false claims of text-to-video generation or third-party app control.
- Added backend tests for valid and rejected website URLs.
